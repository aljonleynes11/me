## The site (built!)

A hand-built **static HTML + Alpine.js** portfolio is included — no build step, no framework.

- `index.html` — the full single-page site (hero, work filter, AI section, skills, about, timeline, contact)
- `assets/styles.css` — custom dark theme
- `assets/README.md` — screenshot instructions + deployment notes

**Run it:** open `index.html` in a browser, or `python -m http.server 8000` from this folder.
**Host it:** GitHub Pages, Cloudflare Pages, Netlify, or Vercel (drag-and-drop).
